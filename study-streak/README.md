# Study Streak

Небольшой консольный трекер учебной активности.

## Запуск

Отметить сегодняшний день:

```bash
python3 study-streak/streak.py --mark
```

Посмотреть статистику:

```bash
python3 study-streak/streak.py --stats
```

Экспортировать список активных дат:

```bash
python3 study-streak/streak.py --export
```

Тесты запускаются командой:

```bash
python3 -m pytest study-streak/test_streak.py
```

Данные сохраняются локально в `study-streak/data.json`. Если файл повреждён, программа сообщает об ошибке вместо тихой потери данных.

## Возможности

- добавить учебную сессию;
- посмотреть статистику;
- узнать текущую серию активных дней;
- экспортировать активные даты;
- запускать команды без интерактивного меню;
- проверять сохранение данных тестами.

Проект создан как маленький ежедневный инструмент для поддержания регулярной работы.
