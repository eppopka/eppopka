# Study Streak

Небольшой консольный трекер учебной активности.

## Запуск

```bash
python3 study-streak/streak.py
```

Команда создаёт локальный файл `study-streak/data.json`, где сохраняются учебные сессии.

## Возможности

- добавить учебную сессию;
- посмотреть статистику;
- узнать текущую серию активных дней.

Проект создан как маленький ежедневный инструмент для поддержания регулярной работы.
