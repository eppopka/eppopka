# Study Streak

**Study Streak** — это лёгкий консольный трекер учебной активности для поддержания регулярных занятий. Утилита сохраняет прогресс локально и позволяет отслеживать ежедневную серию (стрик) без отвлечения на сложный интерфейс.

## Возможности

* **Фиксация прогресса.** Добавляет отметку о сегодняшней учебной сессии одной командой.
* **Статистика и серии.** Подсчитывает общее количество активных дней и текущую непрерывную серию.
* **Экспорт данных.** Выгружает список всех активных дат для резервного копирования или анализа.
* **Работа без меню.** Все действия выполняются напрямую через флаги командной строки, что удобно для скриптов и алиасов.
* **Защита от сбоев.** Проверяет целостность файла `study-streak/data.json` и сообщает об ошибке при его повреждении, предотвращая тихую потерю данных.
* **Покрытие тестами.** Включает набор модульных тестов для проверки корректности записи и чтения данных.

## Быстрый старт

Убедитесь, что у вас установлен **Python 3**. Все команды запускаются из корневой директории проекта.

### Основные команды

* **Отметить сегодняшний день:**
  ```bash
  python3 study-streak/streak.py --mark
  ```
* **Посмотреть статистику и текущий стрик:**
  ```bash
  python3 study-streak/streak.py --stats
  ```
* **Экспортировать список активных дат:**
  ```bash
  python3 study-streak/streak.py --export
  ```

### Запуск тестов

Для проверки корректности сохранения данных и работы логики используется `pytest`:

```bash
python3 -m pytest study-streak/test_streak.py
```

## Хранение данных

Все записи хранятся локально в файле `study-streak/data.json`. Файл создаётся автоматически при первом запуске команды `--mark`.
